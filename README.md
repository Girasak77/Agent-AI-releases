# Agent & AI

แอปเดสก์ท็อปที่รวม AI หลายตัวไว้ในหน้าต่างเดียว ได้แก่ Claude, ChatGPT (Codex), Antigravity, OpenCode และ Freebuff ใช้ได้ 3 โหมด คือ Agent, Code และ Chat

repo นี้เก็บเฉพาะไฟล์ติดตั้งและไฟล์อัปเดต ไม่มีซอร์สโค้ด

## ดาวน์โหลด

ไปที่หน้า [Releases ล่าสุด](https://github.com/Girasak77/Agent-AI-releases/releases/latest) แล้วเลือกไฟล์ตามนี้

| ไฟล์ | ใช้ทำอะไร |
| --- | --- |
| `AI-Agent-Setup.exe` | ตัวติดตั้งสำหรับติดตั้งครั้งแรก |
| `AI-Agent-windows-x64.zip` | ไฟล์อัปเดตที่แอปดาวน์โหลดเอง ไม่ต้องโหลดเอง |
| `AI-Agent-windows-x64.zip.sha256` | รหัสตรวจสอบไฟล์อัปเดต แอปใช้เช็กว่าไฟล์ไม่เสียหาย |

รองรับ Windows 10 และ 11 แบบ 64-bit

## ติดตั้ง

1. ดาวน์โหลด `AI-Agent-Setup.exe`
2. เปิดไฟล์แล้วทำตามขั้นตอน ไม่ต้องใช้สิทธิ์ผู้ดูแลเครื่อง
3. เปิดแอปจากทางลัด **Agent & AI** บนเดสก์ท็อปหรือเมนู Start

ถ้า Windows ขึ้นหน้าต่าง "Windows protected your PC" ให้กด **More info** แล้วกด **Run anyway** หน้าต่างนี้ขึ้นเพราะไฟล์ยังไม่ได้เซ็นรับรองด้วยใบรับรองของบริษัท

ครั้งแรกที่เปิด แอปจะพาตรวจเครื่องมือที่ต้องใช้ และช่วยติดตั้งตัวที่ยังไม่มี AI แต่ละตัวต้องเข้าสู่ระบบด้วยบัญชีของผู้ใช้เอง

## อัปเดต

แอปตรวจเวอร์ชันใหม่ให้เองทุกครั้งที่เปิด และทุก 30 นาที เมื่อมีเวอร์ชันใหม่จะดาวน์โหลดไว้เบื้องหลัง ตรวจรหัส SHA-256 ก่อนติดตั้ง แล้วเปิดแท็บเดิมกลับมาให้หลังอัปเดต

ตรวจเองได้ที่ **ตั้งค่า → อัปเดตโปรแกรม → ตรวจอัปเดต**

โปรเจกต์ ประวัติแชต และการตั้งค่ายังอยู่ครบหลังอัปเดต

## ตรวจไฟล์เอง (ไม่บังคับ)

เปิด PowerShell ในโฟลเดอร์ที่ดาวน์โหลดไว้ แล้วรัน

```powershell
Get-FileHash .\AI-Agent-windows-x64.zip -Algorithm SHA256
```

ค่าที่ได้ต้องตรงกับตัวเลขในไฟล์ `AI-Agent-windows-x64.zip.sha256`
